# 付箋（sticky-notes）

家にいる人への伝言を、付箋のように貼る拡張機能。

- **ウィジェット「付箋（伝言）」**: 貼ってある付箋を新しい順に並べる。高さ 1 段につき 1 列で、はみ出した分は横にめくって見る。
  ＋か付箋を押すと詳細が開き、そこで貼る・はがす
- **貼る**: 伝言（200 文字まで）、書いた人（任意。端末ごとに覚える）、色（黄・ピンク・青・緑）、はがす時期
  （はがすまで・今日中・明日まで・1 週間）。期限を過ぎた付箋は出なくなり、次に書き込んだときにファイルからも消える
- **文字の揃え**: 横（左・中央・右）と縦（上・中央・下）。入りきらない長い文は、揃えにかかわらず頭から出す
- **効果**（iMessage の効果にならう）。選ぶとその場で見本が動き、貼ると、ウィジェットを置いたどの画面でも 1 回動く
  - 付箋の動き: ドン（叩きつける）・大声（大きくなって震える）・そっと（小さく出て広がる）・見えないインク（押すまでぼやけて読めない）
  - 画面の効果: 紙吹雪・風船・ハート（画面いっぱい。押すのは邪魔しない）
  - 「ときどき繰り返す」を付けると、付箋の動きを 5 分ごとに繰り返す（だれも見ていない間に貼られても気付けるように）
  - 貼ってある付箋は、詳細で押すと効果をもう一度見られる
  - 端末の「動きを減らす」設定では動かさない（見えないインクのぼかしは残る）。軽い表示では画面の効果の粒を減らす
- **はがす**: 2 回押し。壁の端末で手が当たってはがれないように
- **音声アシスタント**: `list_sticky_notes`（read）・`add_sticky_note`（low。揃えと効果も選べる）・`remove_sticky_note`（confirm）。
  「〜って伝えておいて」で貼れる
- 付箋は拡張機能のデータフォルダの `notes.json` に置く。40 枚まで。前の版で貼った付箋（揃え・効果を持たない）は、左上・効果なしとして読む
- 貼る・はがすとサーバーが `api.broadcast("changed")` し、どの端末もすぐ読み直す。ポーリング（60 秒）は知らせを取りこぼしたときの保険

## 設定

| 項目 | 環境変数 | 既定 | 用途 |
|---|---|---|---|
| タイムゾーン | `STICKY_NOTES_TIME_ZONE` | `Asia/Tokyo` | 「今日中」「明日まで」の区切り。Docker の中は UTC のことが多いため |

## 組み立て

ほかの拡張機能と同じ（[docs/extensions.md](../../docs/extensions.md)）。

```bash
pnpm build:extension extensions/sticky-notes
```
